# andre_skills

Skills comerciales de Indrox y Zentral usadas por los asistentes de André Forsyth. Cada skill vive en `skills/<id>/SKILL.md`.

| Skill | Cuándo usarla |
|---|---|
| [Indrox deal gates](skills/indrox-deal-gates/SKILL.md) | Aplicar gates MEDDIC con evidencia antes de avanzar etapas TechBrain→BuildPro o Demo→Piloto→Suscripción; qualify-or-kill. |
| [Indrox deal velocity](skills/indrox-deal-velocity/SKILL.md) | Detectar deals zombie y acelerar con mutual action plan; sin usar benchmarks externos como promesa al cliente. |
| [Indrox discovery](skills/indrox-discovery/SKILL.md) | Estructurar discovery SPIN + MEDDIC (Meet 30 min); confirmar ICP y siguiente paso sin pitch de producto ni playbooks de descuento. |
| [Indrox handoffs](skills/indrox-handoffs/SKILL.md) | Armar context packs al pasar DEM→VTA, VTA-04→PT-PRD-01, VTA-03→entrega, o TechBrain→BuildPro→TechEvolution sin perder el porqué compraron. |
| [Indrox ICP qualify](skills/indrox-icp-qualify/SKILL.md) | Calificar o filtrar un lead/cuenta con filtro B.3, anti-ICP y preguntas B.4; enrutar Indrox Core vs Zentral y etiquetar en CRM. |
| [Indrox lost revival](skills/indrox-lost-revival/SKILL.md) | Revivir cerrados-perdidos o pausados con método C&V (No corresponde / Pausa / Interés vigente); aprobación humana y cadencia 4 toques. |
| [Indrox partner referrals](skills/indrox-partner-referrals/SKILL.md) | Perfil de partner ideal, enablement y context pack de referido con permiso; partners solo refieren — sin resale, deal reg, MDF ni comisiones en esta skill. |
| [Indrox pipeline desk](skills/indrox-pipeline-desk/SKILL.md) | Higienizar pipeline en Indrox CRM: deals stale, next step+fecha, motivo de pérdida; reportes mínimos para forecast real. |
| [Zentral activation](skills/zentral-activation/SKILL.md) | Llevar una suscripción Zentral a activación (primer flujo contratado live + primer KR validado) en ≤15 días hábiles PT-PRD-01 y pedir referido. |
| [Zentral pilot conversion](skills/zentral-pilot-conversion/SKILL.md) | Diseñar piloto Zentral pagado/acotado con criterios de éxito y baseline del cliente escritos ANTES de empezar; prohibido lenguaje de free trial. |
