# Indrox discovery

Adaptado de B2B RevOps Skills (MIT, Rutger Katz / Neon Triforce) v1.8.1.

## Cuándo usar

Primera reunión (Meet ~30 min), re-discovery tras silencio, o al preparar demo/TechBrain. Trigger: "discovery", "SPIN", "MEDDIC", "primera llamada", "calificar dolor".

## Reglas duras (kit)

- Solo **SPIN + MEDDIC**. No SPICED por defecto. **Sin playbooks de descuento.**
- No presentar producto entero ni stack técnico. No "fábrica de software" ni precio por hora.
- No ahorros/% no medidos; no free trial; pricing solo D.3 / TechBrain pagado deducible.
- Outbound previo: 4 toques / 14–16 días. CRM: Indrox CRM. Procesos GR-DEM / GR-VTA.

## Objetivo de la reunión

Entender el problema de negocio, confirmar B.3, mapear firmante/champion, acordar **un** siguiente paso fechado.

## Estructura SPIN (empresas que ya operan)

1. **Situación** — Organización (áreas, sedes, personas); herramientas de ventas/ops/finanzas; desde cuándo y con qué volumen real.
2. **Problema** — Qué reconstruyen a mano cada semana; dónde se pierde seguimiento; un ejemplo reciente que salió mal.
3. **Implicancia** — Costo (dinero, clientes, tiempo del dueño); qué pasa al abrir sede o sumar gente; cuánto se enteran tarde.
4. **Necesidad-beneficio** — Si estuviera resuelto, ¿qué decisión distinta?; ¿qué indicador y línea base probarían que funcionó?

No pitch hasta completar Implicancia y Necesidad-beneficio.

## Checklist MEDDIC (notas CRM)

- **M** Indicador + línea base del cliente (ellos definen; no ofrecemos cifras inventadas).
- **E** Quién firma USD relevante; ¿viene a la siguiente?
- **D** Criterios de decisión.
- **D** Proceso y plazos.
- **I** Dolor con ejemplo e impacto.
- **C** Champion interno (ops/finanzas / nuevo responsable).

Presupuesto: rango natural. Core → pre-cot filtra. Zentral → usuarios reales + módulos D.3.

## Salidas posibles

| Salida | Siguiente paso |
| :---- | :---- |
| Core + alcance incierto | Proponer **TechBrain** (pagado, deducible) |
| Core + TDR suficiente | Validación y propuesta BuildPro |
| Zentral + proceso concreto | Demo consultiva sobre **su** flujo (pedir herramientas, dolor, urgencia, datos anonimizados) |
| No encaje | Cerrar; motivo en CRM |

Seguimiento a 48 h post-Meet. Pausar secuencias outbound si hay interés.

## Qué NO hacer

- Hablar descuentos, promos, pruebas gratis o plazos universales.
- Demo de features genéricas o IA "ilimitada".
- Convertir no-fit en venta forzada.

## Handoff

- Pre-filtro → **Indrox ICP qualify**.
- Avance de etapa → **Indrox deal gates**.
- Demo/piloto Zentral → **Zentral pilot conversion**.
- Contexto entre equipos → **Indrox handoffs**.
