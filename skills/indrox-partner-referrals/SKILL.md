# Indrox partner referrals

Adaptado de B2B RevOps Skills (MIT, Rutger Katz / Neon Triforce) v1.8.1.

## Cuándo usar

Reclutar o capacitar quien refiere cuentas, recibir un referido, o pedir referido a cliente activado. Trigger: "partner", "referido", "canal", "BNI", "colaborador".

## Reglas duras (kit)

- Partners **REFIEREN** Indrox Core o Zentral. **No revenden**, no negocian precio/plazos/descuentos.
- Esta skill **no** define: resale, deal registration, MDF, tiers ni comisiones — eso es **acuerdo escrito aparte**.
- No compartir datos del contacto sin **permiso**.
- No LinkedIn Ads; no claims de caso no autorizados; pricing solo lo comunica Indrox (D.3 / Core).
- Pedir referido a clientes **activados** (Zentral: flujo+KR; Core: hito de resultado o revisión).
- CRM: Indrox CRM (fuente partner/referido). Procesos GR-DEM / GR-VTA.

## Ideal partner profile (IPP) — scoring ligero 1–5

| Criterio | Señal |
| :---- | :---- |
| Overlap ICP | Trabaja hospitalidad/asociaciones (Core) o seguridad/BPO/profesionales/agro (Zentral) |
| Complementario | No vende el mismo ERP/proyecto como competencia directa |
| Acceso a decisores | Presenta dueños/gerentes, no solo peers técnicos |
| Motivo > comisión | Relacionamiento, reputación, valor al cliente |
| Dispuesto a enablement | Usa guion de 4 pasos; no improvisa precios |
| Ya refirió informalmente | Señal de compromiso |

Bajo encaje → nurturing relacional, no "programa partner" improvisado.

## Enablement mínimo

1. Kit canónico (Drive) + beachheads + anti-ICP.
2. Pregunta de apertura: *¿Qué información reconstruyen a mano cada semana para vender, operar o cobrar?*
3. Qué **no** decir (anexo I del kit): ahorros, free trial, factory, descuentos.
4. Cómo es una buena intro: problema + permiso + rol + fecha tentativa.
5. Indrox responde SLA a referidos el mismo día laboral cuando sea posible.

## 4 pasos para reconocer cuenta (partner)

1. **Encaje** — beachhead marca correcta.
2. **Dolor visible** — Excel/WhatsApp, retrabajo, cobranzas/objetivos opacos.
3. **Urgencia** — sede nueva, más headcount, nuevo responsable, migración, error caro.
4. **Intro con permiso** — el contacto acepta; presentar a Indrox con contexto.

## Context pack del referido (con permiso)

Registrar en CRM / nota al AE:

- Empresa, rubro, marca sugerida (Core/Zentral).
- Proceso que duele + ejemplo.
- Nombre rol prioridad, decisor si se conoce.
- Permiso explícito + fecha de intro.
- Partner origen (para atribución interna; sin asumir comisión).

Indrox confirma recepción al partner sin revelar datos sensibles de pricing no públicos más allá del kit.

## Pedir referido (post-activación)

Tras **Zentral activation** o hito Core: un ask concreto (*¿quién más pelea con X proceso?*), no blast. Registrar en CRM.

## Qué NO hacer

- Hablar comisiones/MDF/tiers en enablement genérico.
- Dejar que el partner prometa precio, descuento o plazo.
- Tratar partner como reseller de Core.
- Pedir referido antes de activación/resultado.

## Handoff

- Lead referido → **Indrox ICP qualify** → **Indrox discovery**.
- Cuenta activada → pedir referido desde **Zentral activation**.
- Deal → **Indrox deal gates**.
